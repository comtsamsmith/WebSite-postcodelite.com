HTTP/XML : Basics

The HTTP/XML interface is quite simple to use.  We simply call a HTTP URL address, with parameters, and then the HTTP/XML web service returns XML data containing the address information.

The XML returned can be read by any XML compliant language.

First you have to create an online account, and Postcode Lite will send you a data key for accessing the Postcode data.  

Once created, your account will give you access to one postcode area for 30 days.
