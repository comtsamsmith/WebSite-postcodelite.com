AJAX Street Level

This allows a web developer to quickly add a button to your web page, which when pressed fills the Street Level address into your web page.

  • Quick integration into your web page
  • Does not effect the "Look and Feel" of your web page
  • Uses AJAX technology to enhance the user experience
  • Downloadable sample code with instructions
  • Not blocked by Pop-up Blockers
  • No Data Administration costs
  • Will run on most Web servers which allow server side script

 

  

Downloads and Integration Instructions:

  • PHP code
  • Classic ASP code
  • ASP.NET code

The above downloads contain instructions, and require an online account to be opened to give you access to the data via a data key.

Important:

This Interface can be used for use with an organisation, but you must specify each users name, and have a user license to conform with our terms and conditions.
